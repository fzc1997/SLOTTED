# chr21 example

Run from the repository root after installing dependencies:

```bash
python scripts/run_chr21_demo.py
```

The example includes the full GRCh38 chr21 reference, RepeatMasker annotation,
12 real ONT RNA-seq reads, their alignments/indexes and expected outputs.
It runs on CPU in approximately 5 minutes; allow 4 GB of available RAM.

Reads come from [SRR30947478](https://www.ebi.ac.uk/ena/browser/view/SRR30947478)
(LongBench, PRJNA1171488). Reference sequence is GRCh38 chr21 from the alignment
reference, matching UCSC hg38 ignoring case. Annotation comes from the
[UCSC RepeatMasker track](https://hgdownload.soe.ucsc.edu/goldenPath/hg38/database/rmsk.txt.gz).
Source data retain their original terms.

Four reads per candidate-count stratum (K=0, K=1 and 2<=K<=8) were selected
before inference, with full sequence lengths of 200–1,200 bases. All observed
mappings and SA/XA targets for these reads are on chr21; coordinates and
sequences are preserved. See selected_reads.tsv and provenance.json.

The expected tables check software behavior, not accuracy or sample-wide
expression. LM produces 8 candidate-bearing rows; Joint produces 24 rows for
12 reads and two endpoints. The runner checks supplied file hashes and compares
outputs with expected tables. The default output directory includes a timestamp and random suffix.
Use `--out PATH` for an exact directory; existing paths are rejected.

Expected tables were generated by the included CPU workflow with the dependency
versions in requirements-demo.txt. Labels are compared exactly; numerical
fields use absolute and relative tolerances of 1e-5.
